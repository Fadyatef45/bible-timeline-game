# رتّب القصة — Bible Timeline

لعبة تعليمية عربية (RTL) لترتيب أحداث قصص الكتاب المقدس. بدون خادم أو مكتبات.

## التشغيل
افتح `index.html` في المتصفح مباشرة.

## هيكل المشروع
- `index.html` — الهيكل الأساسي وربط الملفات
- `css/style.css` — التصميم (RTL، ألوان البردي والذهبي والأزرق الداكن)
- `js/data.js` — بيانات المستويات والجولات (الأحداث بالترتيب الصحيح + الشرح + المراجع)
- `js/app.js` — منطق اللعبة: الشاشات، السحب والإفلات، التلميحات، النقاط، الحفظ في localStorage

## إضافة جولة أو مستوى
عدّل `js/data.js`: كل جولة `{e:[أحداث بالترتيب الصحيح], x:'الشرح', f:'المراجع'}`.
